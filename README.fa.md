# PIMX WIDE

[فارسی](README.fa.md) · [English](README.md) · [GitHub](https://github.com/MOHAMMADREZAABEDINPOOR/PIMX_WIDE) · [پروفایل PIMX](https://github.com/MOHAMMADREZAABEDINPOOR)

متن، فایل و پوشه را در مرورگر رمز کنید. بسته رمز‌شده را دانلود کنید، در گاوصندوق محلی نگه دارید یا با لینکی که زمان اعتبار و تعداد دریافت مشخص دارد بفرستید. برنامه فارسی و انگلیسی، تم روشن و تیره و استفاده آفلاین از ابزارهای محلی پس از ذخیره‌شدن نسخه انتشار در مرورگر را پشتیبانی می‌کند.

رمزنگاری و رمزگشایی روی دستگاه شما انجام می‌شود. با ساخت لینک اشتراک، بسته رمز‌شده به سرور می‌رود و رمز عبور روی دستگاه می‌ماند. آمار بازدید اختیاری است و به‌صورت پیش‌فرض خاموش است.

## امکانات

- رمزنگاری متن، فایل و پوشه با AES-256-GCM. نسخه ۲ برای ساخت کلید از PBKDF2-SHA256 با ۶۰۰٬۰۰۰ دور استفاده می‌کند و بسته‌های قدیمی هم قابل بازکردن هستند.
- گاوصندوق محلی رمز‌شده با عنوان، برچسب، علاقه‌مندی و پشتیبان رمز‌شده. رمز گاوصندوق از رمز هر بسته جداست.
- ساخت رمز تصادفی و عبارت عبور با مولد تصادفی رمزنگاری مرورگر. عبارت‌های عبور از فهرست واژه‌های EFF ساخته می‌شوند؛ توضیحات در [THIRD_PARTY.md](THIRD_PARTY.md) آمده است.
- بسته قابل‌انتقال، QR و لینک اشتراک اختیاری. محدودیت لینک فقط تحویل از سرور را متوقف می‌کند و نسخه دانلودشده گیرنده را حذف نمی‌کند.
- قفل سریع، قفل خودکار پس از بی‌کاری، کار با صفحه‌کلید و رعایت تنظیمات کاهش حرکت.

## شروع کار

Node.js نسخه 22.12 یا بالاتر لازم است.

```bash
git clone https://github.com/MOHAMMADREZAABEDINPOOR/PIMX_WIDE.git
cd PIMX_WIDE
npm ci
npm run dev
```

سرور Vite ابزارهای محلی رمزنگاری، گاوصندوق و رمزساز را اجرا می‌کند. برای آزمایش لینک اشتراک و آمار مدیریت، سرور Cloudflare Pages را اجرا کنید:

```bash
npm run db:local
npm run dev:full
```

نشانی `http://localhost:8788` را باز کنید. راهنمای رمز مدیریت، اتصال دیتابیس و استقرار در Cloudflare در [SETUP.md](SETUP.md) آمده است.

## تنظیمات و استقرار

بک‌اند از اتصال D1 با نام `PIMX_DB` در [wrangler.toml](wrangler.toml) استفاده می‌کند. ورود مدیر به `ADMIN_PASSWORD_HASH` و `SESSION_SECRET` نیاز دارد. آن‌ها را با `npm run admin:secret` بسازید و رمز را در آرگومان دستور ننویسید. خروجی را برای اجرای محلی در فایل نادیده‌گرفته‌شده `.dev.vars` و برای استقرار در بخش secrets رمز‌شده Cloudflare Pages نگه دارید.

با `npm run build` خروجی را بسازید و پوشه `dist` را همراه `functions/` و دیتابیس D1 تنظیم‌شده منتشر کنید. میزبانی استاتیک برای ابزارهای محلی کافی است؛ لینک اشتراک و آمار مدیریت به Pages Functions نیاز دارند. نسخه منتشرشده باید روی HTTPS اجرا شود.

## دستورها و بررسی‌ها

| دستور | کاربرد |
|---|---|
| `npm run dev` | اجرای سرور توسعه فرانت‌اند |
| `npm run build` | بررسی TypeScript و ساخت نسخه انتشار با پشتیبانی آفلاین |
| `npm run preview` | پیش‌نمایش فرانت‌اند نسخه انتشار |
| `npm run typecheck` | بررسی TypeScript |
| `npm test` | آزمون رمزنگاری، رمزساز و نشست مدیریت |
| `npm run test:e2e` | آزمون مرورگر با سرور Pages و دیتابیس محلی موقت |

برای آزمون مرورگر، Chromium را با `npx playwright install chromium` نصب کنید.

## محدودیت‌ها و نگهداری داده

رمز عبور را جدا از بسته نگه دارید و پیش از حذف فایل اصلی، بازکردن بسته را امتحان کنید. بازیابی رمز وجود ندارد. پاک‌کردن داده‌های مرورگر ممکن است گاوصندوق و تنظیمات را حذف کند؛ یک پشتیبان رمز‌شده در جای دیگری نگه دارید.

استودیو حداکثر ۱۰۰ فایل و ۴۸ مگابایت ورودی در دسکتاپ یا ۲۴ مگابایت در موبایل می‌پذیرد. محدودیت بسته رمز‌شده برای لینک اشتراک ۵۰۰ کیلوبایت است. قفل سریع وضعیت نشست برنامه را پاک می‌کند و گاوصندوق را می‌بندد، اما پاک‌سازی قطعی حافظه مرورگر یا کلیپ‌بورد را تضمین نمی‌کند. فایل‌های دانلودشده روی دستگاه باقی می‌مانند.

این پروژه ممیزی امنیتی مستقل نشده است. جزئیات قالب رمزنگاری و محدودیت‌های ذخیره‌سازی را در [SETUP.md](SETUP.md) بخوانید.

## رفع اشکال

- وابستگی‌ها نصب نیستند: `npm ci` را اجرا کنید.
- لینک اشتراک یا درخواست مدیر انجام نمی‌شود: سرور Pages Functions، اتصال D1 و secrets مدیر را بررسی کنید.
- ابزارهای آفلاین در دسترس نیستند: ابتدا نسخه انتشار را کامل و آنلاین باز کنید. نسخه توسعه service worker ثبت نمی‌کند.
- فایل‌های قدیمی نمایش داده می‌شوند: پروژه را دوباره بسازید و کش مرورگر را تازه کنید.
